## Summary
Undiagnosed leaks and undiagnosed transmission complaints were quoted a repair price instead of a diagnostic. v27.6 adds a narrow diagnostic-dominant classifier gate so those symptoms route to the catalog Diagnostic Inspection ($149), never a repair price, while clearly-named repairs/maintenance stay priced.

## Baseline verification (recorded)
This artifact was generated from the **verified live V27.5 workflow**, not the repository v27.5 file, after a discrepancy was found and resolved by the owner:
- The repository artifact `workflow-v27.5.json` had `availableInMCP=false`.
- Live V27.5 had `availableInMCP=true`.
- All 132 nodes and the full graph wiring matched between repository and live.
- The discrepancy was limited to `availableInMCP` (settings); `executionOrder=v1` matched.
- Resolution: live `availableInMCP=true` is authoritative; the repository `false` was stale drift. v27.6 preserves `availableInMCP=true`.

## Root cause (confirmed — INV-012)
`diagnosticOnly = isVagueSymptom && !hasNamedService`. "leak" was absent from `symptomOnlyKeywords`, and components that co-occur with leaks (coolant/radiator/oil/power-steering/fluid) are in `namedServiceKeywords`, so `hasNamedService` forced `diagnosticOnly=false` and the matcher returned a repair. Bare "transmission" was in neither set, so "transmission acting up" matched `transmission_fluid` ($199).

## Change (one region, one node)
`Estimate Job Ballpark` — added a diagnostic-dominant gate evaluated on `serviceRaw` only, before the existing gate:

    leakSymptom          = /\bleak/i
    explicitReplacement  = /\b(replace|replacement|replacing|install|new|swap)\b/i
    namedComponent       = namedServiceKeywords.test(serviceRaw)
    leakDominant         = leakSymptom && !(explicitReplacement && namedComponent)
    transmissionSymptom  = /\btransmission\b/i AND NOT /\b(fluid|flush|service|change)\b/i
    diagnosticOnly       = (leakDominant || transmissionSymptom) || (isVagueSymptom && !hasNamedService)

## Behavior change (scope)
"leak"/"leaking", and "transmission" without fluid/flush/service/change, route to Diagnostic Inspection ($149) with no repair price — UNLESS the caller explicitly asks to replace a named component (replace/install/new/swap + a known part), which stays priced (named-service override, `tests/diagnostics.md` "Symptom plus a named service").
