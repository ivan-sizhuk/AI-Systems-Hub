## Description
Live QA of the deployed V27.7 classifier found that BUG-013's diagnostic-dominant gate still invents a specific repair price for undiagnosed symptoms phrased with contractions, idioms, specific warning lights, or electrical/vibration synonyms that were outside the symptom lexicon.

## Business Impact
Four natural-language symptoms produced a specific (wrong) repair price and offered to book it: "AC isn't blowing cold" → a/c compressor $899; "the abs light is on" → abs sensor $249; "power windows stopped working" → power steering fluid $109; "there's this shimmy in the steering" → power steering fluid $109. Seven further symptom phrasings fell to a `$0` book-a-visit instead of a diagnostic.

## Expected Behaviour
All of these undiagnosed symptoms route to `diagnosticOnly=true` with no repair price; explicitly named/requested services stay priced.

## Root Cause
The BUG-013 `symptomKeywords` lexicon missed: contractions (`isn't`/`aren't`/`doesn't`), no-start idioms (`won't turn over`), specific warning lights (`abs light`, `oil light`, `battery light`, …), electrical failures (`stopped working`, `power windows`, `flicker`), vibration synonym (`shimmy`), overheating phrasings (`temperature gauge in the red`, `running hot`), pulling synonyms (`drift`, `wander`), and battery/no-start (`needs a jump`). When a gap coincided with a component word, the matcher produced a confident wrong price.

## Fix (V27.8)
Extended `symptomKeywords` to cover these families semantically (contractions, warning-light variants, electrical, shimmy/vibration, overheating variants, drift/pull, needs-a-jump, isn't-driving-right). Added `recharge` to `namedServiceKeywords` so an explicit "AC recharge" request stays carved out. The decision rule `diagnosticOnly = isSymptom && !explicitNamedRequest`, the named-service/self-diagnosis policy, the leak/transmission carve-outs, and the diagnostic message are unchanged.

## Scope
Only the `Estimate Job Ballpark` code node changed (two regex lines). No prompt, catalog/Sheet, matcher, booking, availability, tools, Twilio, calendar, MCP, or other node/setting changed.
