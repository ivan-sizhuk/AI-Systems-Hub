# BUG-014

**Bug ID:** BUG-014
**Title:** matchService prices a repair from a weak/ambiguous single-token match for an undiagnosed symptom
**Severity:** High
**Priority:** High
**Status:** Approved
**Deployment Status:** Not Yet Deployed
**Date Created:** 2026-08-19
**Date Updated:** 2026-08-19

---

## Description
After BUG-013/BUG-016 lexicon hardening, a single search token that stem-collapses into a service key word (e.g. "start" → "starter") still scored ≥ 2 and returned a priced repair with no corroboration. Because "start" and "starter" share a stem, an undiagnosed symptom ("hard to start in the morning") and a named request ("starter") produced **identical** matches and scores.

## Business Impact
Undiagnosed no-start symptoms were quoted a specific **$549 starter replacement** and offered a booking — violating the production rule that an undiagnosed symptom must not receive a specific repair price from a weak/ambiguous match.

## Expected Behaviour
A matched repair is priced only if the caller **explicitly requested** the named service OR **actually said** (a surface form of) the matched service's part word. A weak/ambiguous match without corroboration routes to a diagnostic.

## Root Cause
`matchService` returns `bestMatch` when `bestScore >= 2`. A lone generic/stem token (key hit 2 + rarity 2 = 4) clears the threshold. Score and margin are identical for symptom vs request (same stem), so a confidence threshold alone cannot separate them (Designs A/B proven non-viable by measurement).

## Fix (V27.9 — Design D, corroboration guard)
In `Estimate Job Ballpark`, at the `diagnosticOnly` decision: price a matched repair only if `explicitNamedRequest` OR the matched service's key/core word appears as a **surface whole-word** in the caller's raw text; otherwise route to diagnostic. `matchService` is unchanged.

## Scope
Only the `Estimate Job Ballpark` code node changed (guard added at the `diagnosticOnly` boundary; `matchService`, the diagnostic message, and all other logic unchanged). No prompt-v29, catalog/Services Sheet, matcher scoring, booking, availability, tools, Twilio, calendar, MCP, or other node/setting changed. Existing self-diagnosis/named-service policy preserved.
